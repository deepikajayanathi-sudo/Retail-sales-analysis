# Retail Sales Data Cleaning Using Python

## Project Overview
This project focuses on cleaning and preprocessing a raw retail sales dataset using Python and Pandas. The main objective is to improve data quality and prepare the dataset for further analysis.

## Objectives
- Identify and handle missing values.
- Remove duplicate records.
- Detect and handle outliers.
- Correct inconsistent data.
- Convert columns into appropriate data types.
- Prepare a clean dataset for analysis.

## Tools & Technologies
- Python
- Pandas
- NumPy
- Jupyter Notebook / Google Colab

## Dataset Columns
- Item
- Payment Method
- Location
- Quantity
- Price Per Unit
- Total Spent

## Data Cleaning Steps
1. Data loading and inspection
2. Handling missing values
3. Removing duplicate records
4. Handling inconsistent values
5. Data type conversion
6. Outlier detection and treatment
7. Data validation
8. Exporting the cleaned dataset

## Project Outcome
Successfully cleaned and transformed the raw retail sales dataset into a structured and consistent format, making it ready for further data analysis and visualization.
